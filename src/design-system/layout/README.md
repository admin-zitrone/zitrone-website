# Layout

Reusable layout roles for the design system.

Current implementation:

- `sections.css`: section pattern rhythm, container, stack, cluster, split, grid, card rail, bleed, heading, and copy roles.
- Explicit column variants now live here too: `2-col`, `3-col`, `4-col`, `6/6`, `5/7`, `4/8`, and `editorial`.

Build these before complex sections:

- Container
- Section
- Stack
- Cluster
- Split
- Responsive grid
- Named columns and editorial spans
- Mobile card rail
- Full-bleed media
